# Претензионно-исковая работа

Сайт для ведения претензионно-исковой работы страховой компании по [PRD.md](PRD.md): реестр дел, календарь заседаний, аналитика, автоматические уведомления подразделению по выплатам и бухгалтерии, документы в карточке дела.

Работает на встроенном в Windows PowerShell — устанавливать ничего не нужно.

## Запуск

Дважды щёлкните `start.cmd`. Сервер запустится, и браузер откроет http://localhost:8080/.

Или из PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Port 8080
```

Остановить сервер — `Ctrl+C` в его окне.

### Доступ коллегам по локальной сети

Один раз от администратора разрешите адрес и откройте порт:

```powershell
netsh http add urlacl url=http://+:8080/ user=$env:USERNAME
```

```powershell
netsh advfirewall firewall add rule name="PIR 8080" dir=in action=allow protocol=TCP localport=8080
```

Затем запускайте сервер с параметром `-Bind +`:

```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1 -Bind +
```

Коллеги открывают `http://<имя-компьютера>:8080/`.

## Структура

| Путь | Что это |
|---|---|
| `server.ps1` | HTTP-сервер: статика, API записей, загрузка и выдача документов |
| `public/index.html` | Интерфейс сайта (реестр, календарь, аналитика, уведомления, карточка и форма дела) |
| `public/present.js` | Кнопка «Отчёт в формате презентации» на вкладке «Аналитика»: слайды, скачивание PowerPoint (.pptx, модуль PptxGenJS подгружается из интернета), печать / PDF |
| `public/api.js` | Клиент API: общая база, опрос изменений раз в 2 с, загрузка файлов, имя сотрудника |
| `seed/cases/` | Демонстрационные дела, добавляются при первом запуске (помечены «пример») |
| `data/` | Рабочие данные: `docs/<коллекция>/<id>.json` и `blobs/` с документами. Делайте резервную копию этой папки |

Коллекции соответствуют разделу 5 PRD: `cases`, `notices` (id = `<caseId>--<kind>`), `files`, плюс `users` (ФИО сотрудника из поля «Сотрудник» в шапке).

## API

| Метод и путь | Назначение |
|---|---|
| `GET /api/state?rev=<rev>` | Все записи; если `rev` не изменился — `{"same":true}` |
| `GET/PUT/DELETE /api/doc/<коллекция>/<id>` | Чтение, запись, удаление записи |
| `POST /api/blob` (заголовок `X-Content-Type`) | Загрузка PDF/JPG/PNG до 20 МБ, проверка сигнатуры |
| `DELETE /api/blob/<id>` | Удаление файла |
| `GET /_blob/<id>` | Просмотр файла |

## Отличия от опубликованной версии на claude.ai

- Нет ролей «Наблюдатель / Участник / Редактор»: все, кто открыл сайт, могут вносить изменения. Сотрудник указывает ФИО в шапке — оно показывается у загруженных документов и исполненных уведомлений.
- Изменения коллег появляются в течение ~2 секунд (опрос сервера).
- Если сервер недоступен, сайт работает в локальном режиме с предупреждением, как в PRD.
